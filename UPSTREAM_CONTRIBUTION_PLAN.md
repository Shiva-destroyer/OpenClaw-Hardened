## 🔴 Vulnerabilities Discovered

### 1. Prompt Injection Attacks (Critical)

- **Risk:** Adversarial prompts can manipulate agent behavior
- **Examples:** Jailbreak prompts, role confusion, instruction override
- **Impact:** Unauthorized command execution, data exfiltration, privilege escalation

### 2. Steganographic Payload Injection (Critical)

- **Risk:** Malicious data hidden in image files (LSB steganography, EXIF metadata)
- **Examples:** Commands embedded in image metadata, LSB-encoded payloads
- **Impact:** Silent RCE via seemingly innocent image uploads

### 3. HTML/Web Content Exploitation (High)

- **Risk:** XSS, malicious scripts in web scraping, ReDoS attacks
- **Examples:** `<script>` injection, catastrophic backtracking regex
- **Impact:** Agent context poisoning, DoS, credential theft
